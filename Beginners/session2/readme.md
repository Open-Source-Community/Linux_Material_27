# 🐧 Linux – Session 2

In this session, we'll explore how Linux works with commands and files, understand the Linux file system, and practice essential command-line operations.

## 📌 Session Agenda

1. **Recap** – Review of the previous session.
2. **Prompt, Shell & Terminal** – Understanding the command-line environment.
3. **Command Syntax** – Commands, options, and arguments.
4. **Linux File System Overview** – Exploring the Linux directory structure.
5. **Absolute & Relative Paths** – Navigating the file system.
6. **File Types & Finding Files** – Understanding file types and using `find`.
7. **Inodes & Links** – Understanding how Linux stores files and handles symbolic and hard links.
8. **Pipelines & Redirection** – Connecting commands and managing command output.
